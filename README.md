# LoopWise ♻️

### AI-Powered Circular Resource Advisor

LoopWise helps users decide what to do with an item before throwing it away or replacing it.

Upload an item image, add a few details, and LoopWise suggests whether it could be:

**Repair · Reuse · Repurpose · Donate · Recycle**

## 🌱 Problem

Usable products are often discarded because people are unsure whether they can be repaired, reused, or given another purpose.

## 💡 Solution

LoopWise uses multimodal AI to analyze an item's image and user-provided details, then provides:

- Recommended circular pathway
- Reason for the recommendation
- Second-life idea
- Confidence level
- Safety note

A manual fallback is included when the AI service is unavailable.

## 🤖 AI

**Google Gemini** is used for image + text analysis and circular-resource recommendations.
